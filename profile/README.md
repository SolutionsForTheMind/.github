# NeuroAcoustics

**Solutions for the Mind** — AI-driven acoustic neuromodulation for sleep and memory.

NeuroAcoustics is a deep-tech start-up founded in 2022 by researchers from Sleep Sciences and Brain-Computer Interfaces. We develop a wearable headband that records brain activity during sleep, detects slow-wave oscillations in real time, and delivers precisely timed, non-invasive sound stimulation tailored to each user.
